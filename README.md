# Tech Challenge FIAP - Fase 3

Classificação retrospectiva de alfabetização de alunos a partir da camada
Gold da Fase 2. A reconstrução corrige a fonte de dados, a elegibilidade dos
alunos e o uso de códigos escolares sem estabilidade entre edições.

## Etapas da reconstrução

1. Estrutura, contrato da Gold, validação e rastreabilidade.
2. Análise exploratória e hipóteses antes do treinamento.
3. Baseline, regressão logística e gradient boosting, com validação por escola.
4. Interpretação, aplicação territorial, limitações e entrega reproduzível.

O histórico de commits locais registra essas etapas. Dados individuais e
modelos treinados ficam fora do Git. Fontes externas serão uma comparação
posterior, preservando a referência obtida com a Gold atual.
